# Russian Auto Sandbox

Автомобильная песочница для Windows 10/11 x64: свободные поездки, гараж, персонаж и редактор мира.

## Скачать

[Последняя версия — 0.7.0](https://github.com/plmbir582-oss/russian-auto-sandbox-releases/releases/tag/v0.7.0).
Скачайте `RussianAutoSandbox-Setup-0.7.0.exe` из Assets и запустите. Unity отдельно устанавливать не нужно.

В Assets также есть `RussianAutoSandbox-Portable-0.7.0.zip`: распакуйте целиком и запустите exe внутри папки. Для этой версии установка не требуется.

## Обновить

В игре: **Настройки → Проверить обновления → Загрузить → Установить и перезапустить игру**.
Проверка и загрузка запускаются вручную. Можно также установить новый файл поверх прежней версии.
Личные карты, открытые автомобили и настройки сохраняются.

[Подробности выпуска](https://github.com/plmbir582-oss/russian-auto-sandbox-releases/releases/tag/v0.7.0). В Assets есть управление и список для тестеров.

## Управление

Все клавиши переназначаются в настройках. По умолчанию: G — выйти/сесть; C — камера; F — фары; L — косметический ремонт; F12 — полный экран. Escape открывает главное меню с сохранением сессии. Гараж: ЛКМ — вращение, колесо — масштаб.

## Данные и ограничения

Карты и профиль хранятся в «Документы/Серый район». Этот репозиторий содержит публичные сборки; исходники и личные сохранения не публикуются.
Опоры освещения: [открытые данные Москвы, набор 61762](https://data.mos.ru/opendata/61762), выпуск 28.01.2026. Исходное расположение опор взято из реестра; мешавшие проезду опоры отодвинуты к краям игровых дорог; модели светильников и направления кронштейнов приблизительные. Окружение и автомобили остаются стилизованными.

Установщик пока без доверенной цифровой подписи; Windows Smart App Control может блокировать его запуск.
