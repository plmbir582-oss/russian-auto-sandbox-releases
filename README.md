# Russian Auto Sandbox

Автомобильная песочница для Windows 10/11 x64: свободные поездки, гараж, персонаж и редактор мира.

## Скачать

[Последняя версия — 0.6.1](https://github.com/plmbir582-oss/russian-auto-sandbox-releases/releases/tag/v0.6.1).
Скачайте `RussianAutoSandbox-Setup-0.6.1.exe` из Assets и запустите. Unity отдельно устанавливать не нужно.

## Обновить

В игре: **Настройки → Проверить обновления → Загрузить → Установить и перезапустить игру**.
Проверка и загрузка запускаются вручную. Можно также установить новый файл поверх прежней версии.
Личные карты, открытые автомобили и настройки сохраняются.

## Что изменилось в 0.6.1

- Исправлен старт заводского ЯТБ и электрического ЕрАЗа на траве/грунте, старые дорожные секции получили физическую поверхность асфальта.
- 1232 новых опоры освещения в Ярославском по официальным координатам, ночная работа и отключение при разрушении.
- 12 деревенских домов, исправленные крыши, повреждения стен и разбивающиеся окна.
- Категория «Древняя Русь», городские и сельские церкви/часовни; три типа редактируемых мостов; отдельная кнопка кисти покрытий.
- Материалы салонов, обивка, подвеска в гараже и оптика Газели; болотоход Буханки; семейства Газели/Запорожца.
- Расширенный редактор персонажей и исправленная посадка головы в салонах.
- Главное меню по Escape, отдельные версии автосохранений; распределённая по кадрам генерация травы.

Подробности и список проверок — в выпуске. Изменённая пользователем карта района сохраняется, обновлённая открывается отдельно как «Ярославский 0.6.1».

## Управление

Все клавиши переназначаются в настройках. По умолчанию: G — выйти/сесть; C — камера; F — фары; L — косметический ремонт; F12 — полный экран. Escape открывает главное меню с сохранением сессии. Гараж: ЛКМ — вращение, колесо — масштаб.

## Данные и ограничения

Карты и профиль хранятся в «Документы/Серый район». Этот репозиторий содержит публичные сборки; исходники и личные сохранения не публикуются.
Опоры освещения: [открытые данные Москвы, набор 61762](https://data.mos.ru/opendata/61762), выпуск 28.01.2026. Расположение опор соответствует реестру; модели светильников и направления кронштейнов приблизительные. Окружение и автомобили остаются стилизованными.

Установщик пока без доверенной цифровой подписи; Windows Smart App Control может блокировать его запуск.
